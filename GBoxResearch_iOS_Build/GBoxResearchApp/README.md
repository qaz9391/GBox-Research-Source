# GBox Research iOS Test App

Version: 0.1.0
Mode: Personal Test

## Components

- GBoxResearchApp
- PC Connection
- Input Test
- Anti-Cheat Research
- Result

## Scope

This application is a self-owned research/test client.

It does not implement:
- game injection
- gameplay manipulation
- anti-cheat bypass
- third-party authorization bypass

## Build

Open the source in Xcode on macOS and create an iOS App target using
SwiftUI. Add the five Swift files to the target.

The PC test endpoint must be changed from `127.0.0.1` to the Windows
PC's LAN address when testing from a physical iPhone.
