# GBox Research iOS Build

Purpose:
Personal test application for GBox Research v0.1.

Platform:
iOS

Bundle ID:
com.gboxresearch.app

Deployment Target:
iOS 15.0

Network Test:
Windows PC LAN IP: 192.168.0.104
TCP Port: 60675
Protocol: GBoxResearch v0.1

Files:
- project.yml
- Info.plist
- GBoxResearchApp/
- Network/
- UI/

Build:
1. Open this folder on macOS.
2. Install Xcode.
3. Install XcodeGen.
4. Run: xcodegen generate
5. Open GBoxResearchApp.xcodeproj in Xcode.
6. Configure your own Apple development signing.
7. Build and install on your own test iPhone.

This project is for personal testing and research.
